# MVP Scope

## In scope

- Local Maryland opportunity targeting for solo cybersecurity consulting fit.
- Public-source discovery from configured procurement URLs.
- Candidate extraction with confidence and manual-review fallback.
- Opportunity storage and duplicate prevention.
- Deterministic solo-fit scoring with optional AI overlay.
- Dashboard for ranking and status tracking.

## Out of scope

- Federal procurement sources (SAM.gov).
- Auto-submission or auto-bidding.
- Credentialed portal automation.
- CAPTCHA bypass or anti-bot evasion.
- Multi-user auth and billing.
- CRM automation beyond lightweight status tracking.

## Success criteria

- User can configure sources/keywords via YAML and source API.
- User can run search and get persisted opportunities.
- User can score opportunities and view recommendations.
- User can mark opportunities as Saved, Watch, Pursue, or Skipped.
